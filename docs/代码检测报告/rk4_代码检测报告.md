# rk4.py 代码检测报告

- **检测对象：** `rk4.py`
- **模块用途：** 经典四阶 Runge–Kutta 方法，用于求解一阶常微分方程初值问题。
- **检测方式：** 源码静态审阅与测试设计建议。
- **检测范围说明：** 本文档未执行完整 pytest 测试套件，未完成所有测试用例与独立参考实现对拍。

- Python AST 语法解析：**通过**
- 类：无
- 函数：`_finite`, `rk4_step`, `rk4_solve`
- 导入依赖：`__future__ (from import)`, `math`, `collections.abc (from import)`

## 二、函数/方法级检测设计

### `_finite`

- **功能：** 转换为浮点数并检查有限性。
- **建议测试：** 正常数值、NaN/Inf、不可转换输入。

### `rk4_step`

- **功能：** 执行一次 RK4 积分，返回 x+h 处的近似解。
- **建议测试：** 常导数、y'=y、负步长、h=0、导数返回 NaN/Inf、计算溢出。

### `rk4_solve`

- **功能：** 在指定区间内重复执行单步积分。
- **建议测试：** 正向/反向积分、x0=x_end、末步不足标准步长、浮点精度导致无法推进。

## 三、风险与改进建议

| 风险等级 | 位置 | 检测发现/建议 |
|---|---|---|
| 中 | `rk4_solve` | 循环与浮点位置推进需要边界测试，尤其是极小步长和极大坐标尺度。源码已有无法推进检查，但仍需通过测试确认边界行为。 |
| 中 | `导数函数异常` | 导数函数抛出的异常会向上传播；这可以是合理行为，但应在接口文档与测试中明确。 |
| 低 | `精度验证` | RK4 理论全局误差为 O(h^4)。可用 y'=y、精确解 exp(x) 做步长减半实验，检查误差是否约缩小至原来的 1/16。 |
| 低 | `类型转换` | 导数返回值会被转换为 float；不兼容返回值的异常类型未统一封装。 |

## 五、验收标准

- 常导数问题符合解析解；y'=y 的结果与 exp(x) 在容差内一致。
- 正向与反向积分正确，最终位置严格等于 x_end。
- h=0、非有限初始值、非有限导数结果按约定抛出异常。
- 步长减半后，误差趋势符合四阶方法的预期。
- 步进无法推进时应明确报错，不能无限循环。
