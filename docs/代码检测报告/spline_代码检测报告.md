- **检测对象：** `spline.py`
- **模块用途：** 自然三次样条插值：构建分段多项式并在指定位置求值，区间外使用首段或末段多项式外推。
- **检测方式：** 源码静态审阅与测试设计建议。

## 二、函数/方法级检测设计

### `_validate_nodes`

- **功能：** 检查节点数量、有限性、严格递增与 xs/ys 长度一致。
- **建议测试：** 节点不足、重复或逆序 x、长度不匹配、NaN/Inf。

### `natural_cubic_spline`

- **功能：** 构建自然边界条件下的三次样条系数，并使用 LU 求解内部二阶导数。
- **建议测试：** 两个节点、多个节点、线性函数样例、节点插值精度与自然边界条件。

### `eval_spline`

- **功能：** 通过二分查找定位区间并使用 Horner 形式求值。
- **建议测试：** 节点处、区间内部、左右外推、段数不匹配、非有限 x。

## 三、风险与改进建议

| 风险等级 | 位置 | 检测发现/建议 |
|---|---|---|
| 中 | `运行时依赖` | natural_cubic_spline 在运行时导入 lu.solve，需分别验证包内相对导入和脚本式导入。 |
| 中 | `数值范围` | 节点间距很小或函数值差异很大时，斜率、右端项或系数可能溢出；需补充极端数值测试。 |
| 中 | `eval_spline 输入校验` | 只检查区间数量，没有显式验证每段是否恰有四个有限系数；建议增加段结构与系数验证。 |
| 低 | `外推语义` | 区间外采用首段/末段多项式外推，应在 API 文档与测试中明确。 |
