- **检测范围说明：** 本文档未执行完整 pytest 测试套件，未完成所有测试用例与独立参考实现对拍。

## 二、函数/方法级检测设计

### `_as_list`

- **功能：** 将 Matrix 或二维序列复制为浮点方阵并校验输入。
- **建议测试：** 空输入、非方阵、非有限元素、输入数据是否保持不变。

### `lu_decompose`

- **功能：** 计算 P·A=L·U，返回 L、U 与行置换索引 piv。
- **建议测试：** 无需换行、需要换行、奇异矩阵、1×1；验证 P·A 与 L·U。

### `solve`

- **功能：** 通过前代与回代求解 Ax=b。
- **建议测试：** 已知解构造 b、需要换行、维度错误、非有限 b、奇异矩阵。

## 三、风险与改进建议

| 风险等级 | 位置 | 检测发现/建议 |
|---|---|---|
| 中 | `主元与奇异判断` | 当前通过 pivot == 0.0 判断奇异；近奇异或病态矩阵可能返回数值不可靠的结果。应区分精确奇异检测与条件数/残差评估。 |
| 中 | `solve 前代` | 前代中间向量 y 未单独检查有限性；建议检查中间结果并测试异常数值传播。 |
| 中 | `输入转换` | b 中无法转换为 float 的值会引发转换异常；可明确接口约定并增加异常测试。 |
| 低 | `性能` | 稠密 LU 分解时间复杂度约为 O(n^3)，空间复杂度约为 O(n^2)；大型矩阵的纯 Python 循环可能较慢。 |

## 五、验收标准

- 验证 P·A ≈ L·U，L 对角线为 1、L 为下三角、U 为上三角。
- 发生行交换时，L 中已计算的前缀列同步交换。
- 求解结果满足 A·x≈b，比较时采用绝对/相对容差。
- 拒绝空矩阵、非方阵、NaN/Inf 及长度不匹配的 b。
- 奇异矩阵按约定抛出 ValueError；近奇异矩阵单独评估残差与稳定性。
