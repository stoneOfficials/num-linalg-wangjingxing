- **检测方式：** 源码静态审阅与测试设计建议。

- 导入依赖：`__future__ (from import)`, `math`, `typing (from import)`

## 二、函数/方法级检测设计

### `Matrix.__init__`

- **功能：** 构造矩阵并复制输入数据。
- **建议测试：** 空矩阵、空行、行长度不一致、NaN/Inf、构造后修改原始输入。

### `Matrix.shape`

- **功能：** 返回矩阵形状 (行数, 列数)。
- **建议测试：** 不同尺寸矩阵，确认形状正确。

### `Matrix.__getitem__ / __setitem__`

- **功能：** 支持行索引与 (i, j) 元素索引及赋值。
- **建议测试：** 合法/越界索引、错误元组长度、替换行长度错误、赋入非有限数值。

### `Matrix.swap_rows`

- **功能：** 交换指定的两行。
- **建议测试：** 交换同一行、不同两行、非法索引。

### `Matrix.scale_row`

- **功能：** 将指定行乘以缩放系数。
- **建议测试：** 系数为 0、负数、1、NaN/Inf，以及计算溢出。

### `Matrix.add_row_to`

- **功能：** 执行第 i 行 += factor * 第 j 行。
- **建议测试：** i == j、factor 为 0 或负数、结果溢出、非法索引。

### `Matrix.T`

- **功能：** 返回转置矩阵。
- **建议测试：** 方阵、长方形矩阵；连续转置两次应恢复原矩阵。

### `Matrix.__matmul__ / matmul`

- **功能：** 执行矩阵乘法。
- **建议测试：** 维度兼容与不兼容、非方阵、单位矩阵、零矩阵、两种实现对拍。

### `Matrix.det`

- **功能：** 通过带部分主元的消元计算行列式。
- **建议测试：** 1×1、2×2、需要换行、奇异矩阵、非方阵及参考实现对拍。

### `Matrix.to_list / __repr__`

- **功能：** 返回列表副本并提供对象表示。
- **建议测试：** 返回列表的独立性、repr 输出内容。

## 三、风险与改进建议

| 风险等级 | 位置 | 检测发现/建议 |
|---|---|---|
| 中 | `Matrix.scale_row` | 缩放后未显式检查结果是否有限。有限数相乘仍可能溢出为 inf，建议先计算临时行并验证后再更新内部状态。 |
| 中 | `Matrix.swap_rows / 索引操作` | 部分操作依赖 Python 原生索引异常；建议通过测试明确越界行为，必要时统一异常约定。 |
| 中 | `Matrix.det` | 浮点消元对病态矩阵可能存在较大相对误差，测试应使用容差而非直接比较浮点数是否完全相等。 |
| 低 | `matmul` | 输入经过有限性校验，但乘法累加仍可能溢出；可在结果生成后增加有限性检查。 |
