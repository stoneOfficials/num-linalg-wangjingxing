# 项目代码优化提示词

## 一、背景

这是一个基于 Python 实现的基础数值计算项目，主要用于学习和实践线性代数、矩阵运算、常微分方程数值求解和插值算法。

项目包含四个核心文件：

- `src/matrix.py`：矩阵基础运算，包括矩阵乘法、转置、行变换和行列式计算。
- `src/lu.py`：带部分主元的 LU 分解，以及利用分解结果求解线性方程组。
- `src/rk4.py`：经典四阶 Runge–Kutta 方法，用于求解常微分方程初值问题。
- `src/spline.py`：自然三次样条插值，包括样条系数计算、插值和区间外推。

项目面向 Python 学习者和数值计算初学者，重点是算法正确性、代码可读性和数学原理的清晰实现。目前四个模块已有初始实现，需要在尽量保留现有代码和接口的基础上进行检查与优化。

## 二、范围

**允许修改：**
- `src/matrix.py`
- `src/lu.py`
- `src/rk4.py`
- `src/spline.py`

可以根据需要修改以上文件中的内部实现、边界检查、异常处理和必要的辅助逻辑。

**绝对不动：**
- 不随意修改已有公开类、函数、方法的名称和参数签名。
- 不改变已有公开 API 的返回值类型、数据结构及既定语义。

## 三、目标

按照以下优先级进行优化：

1. **正确性优先：** 检查各模块的算法实现是否符合数学定义，修复计算错误、边界条件错误、矩阵行交换错误及模块间调用问题。
2. **数值稳定性：** 检查浮点误差、主元选择、奇异矩阵判断、积分步长控制和样条系数计算，避免不合理的数值处理。
3. **健壮性：** 对空矩阵、非法维度、非矩形输入、零步长、节点顺序错误及其他非法输入进行合理检查，并提供清晰的异常信息。
4. **模块兼容性：** 确保矩阵模块、LU 分解模块和样条模块之间的调用正确，兼容项目现有的导入方式与返回值约定。
5. **可读性：** 优化变量命名、控制流程和必要的注释，使代码适合初学者阅读，能够对应数学公式理解实现过程。
6. **性能与内存：** 在不影响正确性和可读性的前提下，减少不必要的数据复制、重复遍历和中间对象；不进行缺乏实际收益的微优化。
