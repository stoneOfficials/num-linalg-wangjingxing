### 一、LU 分解要求

1. `A` 是方阵，以二维 `list` 形式传入。计算前必须复制矩阵，不能修改调用者传入的 `A`。

2. 分解满足 \(PA=LU\)，其中：
   - `L` 是下三角矩阵，对角线元素全部为 `1`。
   - `U` 是上三角矩阵。
   - `piv[i]` 表示分解后第 `i` 行来自原矩阵 `A` 的第 `piv[i]` 行，即 `(PA)[i] = A[piv[i]]`。

3. 使用部分主元法：处理第 `k` 列时，在第 `k` 行到最后一行中，选择该列绝对值最大的元素所在行，并将其交换到第 `k` 行。

4. 行交换规则：
   - `U` 交换整行。
   - `L` 只交换第 `0` 列到第 `k-1` 列中已经计算好的乘数，保持对角线元素为 `1`。
   - `piv` 中对应的元素也必须交换。

5. 如果主元绝对值小于 `1e-12`，抛出 `ValueError`，异常信息中必须包含“奇异矩阵”。

6. 如果 `A` 不是非空方阵，也抛出 `ValueError`。

### 二、消元规则

对于每个 `k`，对所有 `i > k`：

- `factor = U[i][k] / U[k][k]`
- 将 `factor` 写入 `L[i][k]`。
- 更新 `U` 的第 `i` 行：第 `i` 行减去 `factor` 乘以第 `k` 行。

### 三、求解线性方程组

`solve(A, b)` 按照以下步骤实现：

1. 调用 `lu_decompose(A)`。
2. 根据置换向量构造 `pb`：`pb[i] = b[piv[i]]`。
3. 前代求解 `L y = pb`。由于 `L` 的对角线元素全部为 `1`，不需要再除以对角线元素。
4. 回代求解 `U x = y`。
5. 返回普通 Python `list`。

如果 `len(b)` 不等于矩阵 `A` 的阶数，抛出 `ValueError`。

请编写 `src/spline.py`，实现自然三次样条插值。

保持以下函数名及参数不变：

- `natural_cubic_spline(xs, ys) -> list[tuple]`
- `eval_spline(segments, xs, x) -> float`

### 一、输入与返回格式

1. `xs` 和 `ys` 分别表示插值节点的横坐标和纵坐标。
2. `xs` 必须严格递增，`xs` 与 `ys` 的长度必须相同，且至少包含两个节点。否则抛出 `ValueError`。
3. 计算前，将 `xs` 和 `ys` 复制并转换为浮点数，不得修改调用者传入的列表。
4. 返回值 `segments` 是一个列表，每个元素为 `(a, b, c, d)`。
5. 第 `i` 段对应区间 `[xs[i], xs[i+1]]`，令 `t = x - xs[i]`，该段的插值多项式为：

   `S(x) = a + b*t + c*t**2 + d*t**3`

6. 段数必须等于节点数减 `1`。

### 二、求解二阶导数

设各节点处的二阶导数为 `M[i]`。自然边界条件为：

- `M[0] = 0`
- `M[n-1] = 0`

其中 `n` 为节点数。

定义相邻节点间距：

`h[i] = xs[i+1] - xs[i]`

只对内节点 `i = 1, ..., n-2` 建立方程：

`h[i-1]*M[i-1] + 2*(h[i-1]+h[i])*M[i] + h[i]*M[i+1] = 6*((ys[i+1]-ys[i])/h[i] - (ys[i]-ys[i-1])/h[i-1])`

由于两端二阶导数均为 `0`，未知数只有 `M[1]` 到 `M[n-2]`。

1. 使用 `src.lu` 中的 `solve(系数矩阵, 右端项)` 求解三对角线性方程组。
2. 只有两个节点时，不存在内节点，不要求解 `0` 阶矩阵；直接令两端二阶导数为 `0` 并计算该段系数。
3. 注意：如果通过包导入运行，应优先使用相对导入；如果作为独立模块运行，可使用适当的导入回退方式。

### 三、计算样条系数

第 `i` 段的系数为：

```python
a = ys[i]
b = (ys[i+1] - ys[i]) / h[i] - h[i] * (2*M[i] + M[i+1]) / 6
c = M[i] / 2
d = (M[i+1] - M[i]) / (6*h[i])
```

### 四、检验要求

1. 对节点 `(0, 0)`、`(1, 1)`、`(2, 0)`：
   - 三个节点上的插值结果必须分别为 `0`、`1`、`0`。
   - `x = 0.5` 和 `x = 1.5` 处的插值结果都应为 `0.6875`。

   该例中，`h = 1`，`M[0] = M[2] = 0`，内点方程为 `4*M[1] = -12`，因此 `M[1] = -3`。第一段系数应为 `(0, 1.5, 0, -0.5)`。

2. 对于不等间距节点 `(0, 0)`、`(0.4, 1.2)`、`(1.1, -0.3)`、`(2.0, 0.5)`、`(3.2, 0)`，每个节点上的插值结果都必须等于给定的 `y` 值。

3. 在每个内节点处，左段与右段的一阶导数、二阶导数必须连续：
   - 一阶导数为 `b + 2*c*t + 3*d*t**2`。
   - 二阶导数为 `2*c + 6*d*t`。

   对于左段，取 `t = h[i]`；对于右段，取 `t = 0`。两侧对应导数的值应相等，允许正常的浮点数误差。

4. 以下情况均应抛出 `ValueError`：
   - `xs` 和 `ys` 长度不同。
   - 节点少于两个。
   - `xs` 不是严格递增。

请编写 `src/rk4.py`，实现经典四阶 Runge-Kutta（RK4）数值积分方法。

保持以下函数名及参数不变：

- `rk4_step(f, x, y, h) -> float`
- `rk4_solve(f, x0, y0, x_end, h) -> tuple`

### 一、单步积分

`rk4_step(f, x, y, h)` 根据以下公式计算单步结果：

```python
k1 = f(x, y)
k2 = f(x + h / 2, y + h * k1 / 2)
k3 = f(x + h / 2, y + h * k2 / 2)
k4 = f(x + h, y + h * k3)

y_next = y + h * (k1 + 2*k2 + 2*k3 + k4) / 6
```

返回 `y_next`。

### 二、完整积分

`rk4_solve(f, x0, y0, x_end, h)` 从初始点 `(x0, y0)` 积分到 `x_end`，返回两条等长的列表 `(xs, ys)`。

1. `xs[0]` 和 `ys[0]` 必须分别为 `x0` 和 `y0`。
2. 每完成一步积分，就将新的 `x` 和 `y` 追加到列表中。
3. 当 `x_end == x0` 时，直接返回 `([x0], [y0])`。
4. 当 `h == 0` 时，抛出 `ValueError`，异常信息必须包含“步长”。
5. 最后一个 `xs` 元素必须严格等于 `x_end`。

### 三、步长处理

1. 由于浮点数累加可能产生误差，例如 `0.1` 累加十次不一定严格等于 `1.0`，如果区间长度近似为步长的整数倍，应计算步数，并使用 `区间长度 / 步数` 作为实际步长。积分完成后，将 `xs[-1]` 设置为 `x_end`。
2. 如果区间长度不能被 `h` 整除，前面使用完整步长，最后一步缩短为剩余距离，使终点严格等于 `x_end`。
3. 不得将自然常数 `e`、某个具体微分方程或固定步长写死在函数中。函数、起点、终点和步长均由参数提供。

### 四、检验要求

1. `rk4_step(lambda x, y: y, 0, 1, 0.1)` 只计算一步。

   调用 `rk4_solve(lambda x, y: y, 0, 1, 0.1, 0.1)` 时，两条列表的长度均为 `2`，终点 `xs[-1]` 为 `0.1`。

2. 对于微分方程 `y' = y`，初值 `y(0) = 1`，步长 `h = 0.1`，积分到 `x = 1`：
   - `xs[-1]` 与 `1` 的误差小于 `1e-9`。
   - `ys[-1]` 与 `e` 的误差小于 `1e-4`。

3. 将步长改为 `0.05`，再次积分到 `1`：
   - 终点 `y` 的误差必须小于步长 `0.1` 时的误差。
   - 大步长误差除以小步长误差的比值应在 `8` 到 `32` 之间。四阶方法在步长减半时，误差理论上约缩小为原来的 `1/16`。

4. 对于微分方程 `y' = -y`，初值 `y(0) = 1`，步长 `h = 0.1`，积分到 `1`，终点结果与 `e^(-1)` 的误差小于 `1e-4`。
